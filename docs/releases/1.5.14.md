# CourseForge 1.5.14

## Summary

Fix: Add textbook data quality signals and duplicate comparison guidance

## What Changed

- Textbook cards now always reserve a cover slot and show `No Image` when cover data is missing.
- Added right-aligned textbook data status chips (`Complete`, `Partial`, `Empty`) in list cards.
- Added captured-content stats per textbook (chapters, sections, vocab, equations, concepts, key ideas).
- Added deterministic `Best Data` indicator to highlight the strongest non-archived textbook entry.
- Extended startup duplicate-resolution dialog with the same quality/status signals for consistent comparison.
- Added repository-level single-pass stats aggregation (`getTextbookContentStatsMap`) to avoid N+1 count queries.
- Updated integration coverage and architecture/onboarding docs for rationale and maintenance guidance.

## Why

Teachers need to quickly compare duplicate textbook records and identify weak/incomplete captures at login without drilling into each hierarchy. These comparison signals reduce cleanup friction and improve confidence when selecting the record to keep.
