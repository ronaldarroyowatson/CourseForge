# CourseForge 1.6.0

## Summary

Feature: Admin upgrade with School Admin and Super Admin workflows

## What Changed

- Added School / District affiliation setup on Settings with directory lookup and manual entry fallback.
- Added School Admin navigation and role-gated school-scoped admin operations.
- Added Super Admin navigation and role-gated global operations, including role management and promotion request review.
- Fixed Super Admin dashboard global stats to use authoritative sources:
  - Firebase Auth user totals
  - Firestore collection-group textbook totals
  - Aggregated OCR and premium usage counters
- Updated Settings school and district placeholder helper copy to generic onboarding text.

## Why

The admin model needed to scale beyond a single global admin screen so schools can manage local membership and moderation while super admins retain global visibility and control. The stats fix ensures the super-admin dashboard reflects real production-backed totals instead of sparse mirror data.
