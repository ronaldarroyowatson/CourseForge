# CourseForge 1.6.30

## Summary

Fix Azure backup reliability, secret wiring, and installer/index alignment

## Included

- Hardened Super Admin Azure backup runtime with explicit job lifecycle reporting (`running`, `success`, `partial`, `failed`).
- Added backup single-flight lease guardrails and stale-run reconciliation to prevent duplicate/manual-schedule overlap.
- Bound Azure Cosmos connection string to Firebase Secret Manager (`AZURE_COSMOS_CONNECTION_STRING`) for secure runtime access.
- Added Firestore collection-group index definitions for backup target collections and deployed index configuration via `firebase.json` + `firestore.indexes.json`.
- Updated Super Admin backup UX for compact history cards, scroll/fade affordance, and expandable detail rows.
- Synced installer outputs and checksums through the remote Windows/Linux matrix before release publish.
