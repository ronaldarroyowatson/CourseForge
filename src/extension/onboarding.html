CourseForge Capture Setup

Complete this once after install so multi-page TOC capture works without interruptions.

1) Run Capture Permission Check

Click the button, choose a tab/window/screen in the browser picker, then allow capture.

Waiting for permission check.

2) macOS Screen Recording (Edge/Chrome)

  1. Open System Settings on macOS.
  2. Go to Privacy & Security > Screen Recording.
  3. Enable permission for Microsoft Edge or Google Chrome.
  4. Restart the browser if macOS asks you to.

3) If You Still See NotAllowedError

  1. Confirm Screen Recording is enabled in macOS settings.
  2. Close other active screen sharing sessions and retry.
  3. Use Upload Image as fallback while resolving permission settings.
